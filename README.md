# Kitchen OS — Build Journal

A living, version-controlled journal for **Kitchen OS** — an AI-native kitchen-automation venture. Software-first, hardware-last.

- **The doc:** [`index.html`](index.html) — open it in a browser, or view the published GitHub Pages site.
- **What it covers:** the venture thesis, the phased roadmap, the Kitchen OS v0.1 scope (recipe schema, extraction pipeline, tech stack, milestones, success criteria), the decisions log, and a changelog.

## Keeping it alive

Each work session:

1. Edit `index.html`.
2. Add a new entry at the **top** of the Changelog section.
3. Bump the **Doc rev** and **Last updated** timestamp in the hero and footer.
4. Commit & push — GitHub Pages redeploys automatically.

The newest learning always sits closest to the top.
